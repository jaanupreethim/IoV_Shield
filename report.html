RL-Based Dynamic Packet Routing for Hierarchical IoV IDS

Evaluation Timestamp: 20261019_133329 | Test Dataset: CIC-IoV2024 (1,000 samples)

Executive Summary

This report compares three packet routing architectures: (1) Flat (no hierarchy, every packet classified at the Near-Edge), (2) Fixed Hierarchy (Uddin et al., 2025), and (3) Proposed RL Dynamic Routing under both normal operating conditions and DoS attack burst floods.

2. Key Findings & Tradeoffs

Where RL Outperforms Fixed Hierarchy: During attack bursts, Fixed Hierarchy forces every suspicious packet through congested RSUs, causing severe queue buildup. The RL agent dynamically identifies congested links and routes traffic away from the congested RSU directly to the Near-Edge node via 5G cellular shortcuts, reducing burst latency while preserving detection fidelity.

Tradeoffs: When traffic is light, the Fixed Hierarchy incurs minimal hop overhead for clear benign traffic. The RL agent requires initial offline exploration to learn optimal thresholds.
